# Aas Paas News

Live Hindi & English daily news hub with Google News RSS integration.

## Live Website

Once GitHub Pages is enabled, visit: https://rchaurasiya1075.github.io/aas-paas-news/

### Enable GitHub Pages
1. Go to repo Settings > Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save

Features:
- Live news from Google News (Hindi/English)
- Language toggle
- Dark mode
- Search, categories, bookmarks
- User news submission
- Responsive design
